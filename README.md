# Banana Ripeness Classifier (Minion Edition)

A Next.js application comparing 3 banana classification experiments:
1. **PCD + ML** (`best_model.joblib`)
2. **Raw + MobileNetV2** (`best_finetuned_model.keras`)
3. **PCD + MobileNetV2** (`best_mixed_model.keras`)

## Getting Started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or port 3001 if port 3000 is occupied).
